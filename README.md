# BoboLauncher

Лаунчер клиентов Minecraft для Windows 10/11 x64.

## Скачать

[Скачать BoboLauncher.exe](https://github.com/svinota2544-coder/BoboLauncher/releases/latest/download/BoboLauncher.exe)

[Все версии и список обновлений](https://github.com/svinota2544-coder/BoboLauncher/releases)

## Как пользоваться

1. Скачайте BoboLauncher.exe и запустите его.
2. Выберите клиент и нажмите «Установить».
3. После установки нажмите «Запустить».

Нужная Java и библиотеки загрузятся автоматически. Для Expensive также включён отдельный Python. Устанавливать Java, Gradle или Python вручную не требуется.

Игровой ник задаётся в настройках лаунчера. Там же можно восстановить или обновить файлы выбранного клиента. Конфиги открываются кнопкой «Конфигурации».

## Клиенты

NightShift, VegaLine, QuickClient, Expensive, DeadCode, Wild, Delta, Dimasik, Nursultan, Rockstar, Rise-Vega, WexSide и Metadon.

Файлы ZIP и каталога в разделе Releases предназначены для автоматической установки. Вручную скачивать их не нужно.
